# Royal Logics - TV Repair Services

A modern, high-converting landing page and lead-capture website for **Royal Logics**, a premier TV repair business based in Vijayanagar, Bengaluru. 


## 🚀 Features

* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
* **Lead Generation Form:** Integrated booking system that instantly sends customer requests to Google Sheets (via SheetDB webhook).
* **Services Showcase:** Clear, visual grid explaining common TV issues (Power, Screen, Backlight, Smart TV connectivity).
* **Modern Tech Stack:** Built for speed, performance, and accessibility.

## 🛠️ Built With

* **Frontend Framework:** React (using Vite)
* **Styling:** Tailwind CSS
* **UI Components:** shadcn/ui & Radix UI
* **Icons:** Lucide React
* **Data Collection:** SheetDB Webhook
